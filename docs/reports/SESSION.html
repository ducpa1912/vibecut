The ask

A paid, offline macOS editor: import one long video, find scenes, remove burned-in text, edit script/voice/captions, render 1080p.

The business frame

$29 one-time. Optional render subscription and a separate DuckClean trial. The cost model was part of the brief, not an afterthought.

The hard question

“Will LaMa run quicker on GPU, and can a better clean-text model replace it?” Six days later that question was still open, with numbers.

Detection

4 fps stills, Apple Vision OCR, edge-text crops, tracklets → clean layers. First frame is read by a separate seek.

Fill

Per span: work area = hole + context, LaMa keyframes, blend/carry, cached clip. The render reads the clip, not the source.

Render

Cut clips, apply fill clips or blur, burn captions, mix voice/dub/music/SFX, encode 1080p H.264.

The limit, stated once

A per-frame model cannot rebuild a plate it has never seen. On moving food the fill smooths and invents. That is a model limit, not a padding bug. The app now measures the motion per line, shows it before the render, and offers Blur per line. Replacing the model is the only real fix.

Apple silicon (M1/M2) and runtime fixes

What actually had to change to run on this Mac.

FixWhy
arm64-only build, macOS 26 targetSingle-arch app, ad-hoc signed for local use. App Store needs a real identity; not attempted.
Bundled LGPL ffmpeg + ffprobe + libdav1dSystem ffmpeg is not guaranteed and GPL builds cannot ship. AV1 input needs dav1d beside the helper.
Browser-playable proxyWKWebView cannot play the HEVC source reliably. The editor serves an H.264 proxy; the render still uses the source.
LaMa rates per chipMeasured: CPU ~6 s a unit, MPS ~0.95 s, CoreML 32× slower. GPU is the default; the bundle carries torch + big-lama.pt (981 MB). CPU is an optional 198 MB Settings download; both are selectable in Render and Clean Focus.

Sidecar handshakeSwift reads the port from the sidecar's first stdout line within 12 s. A cold PyInstaller start can exceed it; kill an orphan sidecar before relaunching.
Xcode + xcodegenCommand Line Tools alone cannot build the app. Xcode 26 plus xcodegen generates the project from project.yml.
Signing key passphraseCommits sign with an SSH key that prompts. Branch history is unsigned because the passphrase was not available; commits use -c commit.gpgsign=false.

Limits

What this session did not solve.

Clean

LaMa invents moving texture. A per-frame model cannot recover food that moved under the caption. Blur is the honest fallback; the model is the real fix.

Render cost

Cache version 12 invalidates every stored fill. A 25 s slice was still running after 42 min and was stopped. A cold 160 s render is hours, not minutes.

Editor

Trim works. Split, reorder and remove-silence do not. Aspect switching and auto-frame are absent. One project at a time.

Distribution

No DMG. Unsigned archive only. Export fails without a team. Screenshots use internal fixture footage.

Layout

Render ends at 60% height; the inspector clips its fifth row; three timeline lanes are empty; portrait Preview keeps side paper. Proposals exist, none shipped.

Business

The cost model was never tested. No tenant, quota, billing or GPU path exists. NLLB cannot ship as a paid default.
