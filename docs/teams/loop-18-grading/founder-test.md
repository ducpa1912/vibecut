# Loop 18 — founder test

1. Open **Edit → Cut → Look**. **Must see:** Exposure, Contrast, Saturation, Temperature.
2. Drag **Exposure** to +80. **Must see:** the picture brightens while you drag.
3. Release. Reload the window. **Must see:** the slider is still at +80.
4. Drag **Saturation** to −100. **Must see:** the picture goes grey.
5. Drag **Temperature** to +100. **Must see:** the picture warms.
6. Press **Reset grade**. **Must see:** all four return to 0 and the picture is neutral.
