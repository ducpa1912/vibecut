## Built

### #13 — closing payoff and spread picks (`clipset.py`)

- A sentence now counts as closing when its text ends in `.`, `!`, `?`, `。`, `！` or `？` (a closing quote or bracket may follow) **and** the next source sentence starts at least 350 ms after it ends. The final sentence in the source closes on punctuation alone.
- Candidate endings prefer closing sentences. For each start, closing endings replace terminal-only endings inside the min/max window; a start with no closing ending keeps its terminal endings, so the candidate pool does not shrink to filler.
- `payoff_position` gives a closing payoff 1.0, terminal punctuation without the pause 0.92, and a non-terminal ending 0.35.
- Each story carries `payoff_closing: bool` for the caller and the founder check.
- Selection adds a centre-spread penalty: a pick whose centre is within `15%` of the source length of an earlier pick loses up to 0.06. The penalty is dropped when no spread option remains (all usable candidates are inside a band, or there are no more candidates than the request needs). The older 8-second proximity term stays.

### #14 — trim from the Edit timeline (`timeline.js`, shared helpers in `stories.js`)

- The Sentences lane has two drag handles: **Trim the story start** and **Trim the story end**. Pointer and keyboard (arrows, Home, End) both snap to whole-sentence bounds. A story always keeps at least one sentence.
- `stories.js` exports the shared pure helpers: `sentenceSpans` (groups output-time clips by sentence id), `nearestSentenceBoundary`, `trimStoryRange` and `outsideLayerIds`.
- A committed trim sends the sentence ids through the existing `PATCH /api/jobs/{job_id}/clip-sets/{set_id}` `stories` body. No new backend route.
- After the PATCH, the timeline rebinds the current Edit through the existing `POST /api/jobs/{job_id}/edits` route. The server builds a new Edit version from the current head with the new `story_ref` clip hash and duration; existing layers are kept. This replaces the old “range change starts a fresh Edit” behaviour.
- Layers that cross or sit outside the new bounds are marked with a dashed bar, `data-outside="1"`, an “outside the trimmed story” title, a header chip (`N outside`), and a status sentence. They are not deleted.
- The timeline keeps the trimmed story and duration through later `setData` calls that still carry the pre-trim story (the surrounding Edit screen is not an owned file). Reopening the story reads the rebound Edit and the new clip set.

## Known gaps

- **The surrounding Edit screen keeps the old duration.** The timeline, its status line and the persisted Edit use the trimmed bounds. The preview and the screen header read the duration they loaded until the story is reopened. If a layer is changed before that, the old Edit head returns 409; the existing handler reloads the new head and retries, but the founder may see the “changed in another window” notice once.
- **Start trim flags layers but does not shift them.** Layers are kept in output time. A layer near the old start may now sit over different source content; it is not remapped. The timeline flags anything that crosses the shorter duration.
- **The caption track is not rebuilt.** Captions keep their old clip hash and cue times until Captions is rebuilt. Cues beyond the new end are flagged in the timeline.
- **Trim is shrink-only from the timeline.** The handles only take sentences away. The Stories cards' ± start/end controls still widen a range.
- **Spread is a penalty, not a hard constraint.** A much higher-scoring neighbour can still win. The penalty is dropped when the pool has no spread option.
- **The final source sentence closes without a measured pause.** There is no next sentence to measure against.
- **Job id source.** The Edit document has no job id and `edit/index.js` is not owned, so `timeline.js` reads `vibecut.studio.job` from localStorage (the same key the shell writes) before the PATCH.
- **No live browser drag smoke.** The desktop browser was disconnected in this session. The Node tests cover the pure snap/trim/flag helpers and the module import; the TestClient tests cover the PATCH and Edit rebind; the founder table covers the drag itself.
