# R3 T4 — Import/Check progress and speech

**Branch:** `rv/r3-t4-progress-speech`
**Base:** `refactor-3-base` = `7e998d1`
**Scope:** T4 in `ROADMAP.md` lines 134–138.

## Summary

- Import now maps scan, audio, thumbnails, frame reading, crop tracking, smoothing, speech and scoring into fixed stage bands. Values never move backwards, end just below 1.0, and the app keeps its single `update_job`/`save_job` commit path.
- Crop owns 0.58–0.82 instead of 0.66–0.68. Its frame pass stops at 55% of that band, then “Smoothing crop paths · n / N” carries the rest. `N / N` is never printed for the frame pass.
- Added measured-ETA decoration after 10%: “about 18 s left”; before that, “estimating”; when the rate window is too thin, elapsed + stage (“12 s so far”). The estimate is positive and smoothed (1.5× up / 0.55× down per update, capped at 1 h).
- Speech progress has a 2.5 s heartbeat from local Whisper and Apple speech. Check frame extraction reports ffmpeg position instead of sitting at 5%.
- Cancel reading now reaches every ffmpeg child in the analysis: the scene scan, `_run` commands, frame extraction and the thumbnail/tracking thread pools. They run in their own process groups and the existing `stt` cancel event is propagated into worker threads. Vision is checked between 8-frame batches.
- Speech language is auto by default. Whisper and cloud engines omit `--language`/`language`; Apple is skipped when an auto-capable engine follows, because Apple cannot detect a language. Explicit non-English options still run Apple with the selected locale.
- Added `pipeline.retry_speech(job, job_dir, options, progress)`: re-extracts audio, re-runs only STT, attaches speech to the existing scenes and returns a transcript/engine patch. It never reads frames and never writes `job.json`.
- Check warnings now carry `speech_state`: `off`, `engine_empty`, `no_speech`, `no_audio`, `read` or `unknown`. “Speech was on, but no engine returned a transcript” is separate from “Speech was off at import”.
- Check UI shows the measured source length before running, a client-side measured ETA after 10%, elapsed + stage when the rate is unavailable, a monotonic percentage, and source length while running.
- Disk refusals say free, reserve and shortfall in GB. Path reads are marked in place: a real path source (≥ 1 KiB) does not reserve the 5 GB copy/render floor; uploads and renders still do.

## Known gaps

1. **Speech retry route is missing.** `pipeline.retry_speech(...)` is implemented and tested, but no owned file has a route. `POST /api/jobs/{job_id}/reading/retry` re-runs the whole analysis and only accepts cancelled/failed/interrupted jobs; it is not a speech-only retry. A route such as `POST /api/jobs/{job_id}/speech/retry` must call `pipeline.retry_speech` and apply its `transcript`, `engine` and `scenes` in one `update_job`. The Check UI therefore has no retry button in this branch.
2. **Check cancel endpoint is missing.** `POST /api/jobs/{job_id}/reading/cancel` stops analysis only. Check runs on `CHECK_POOL` in `routes_check.py`, which is outside this track’s files. `check.js` offers “Cancel reading” only while the job itself is still reading.
3. **Vision cancellation is batch-granular.** `_probe_images_progress` stops submitting new batches, but `vision.probe_images` is a `vision.py` subprocess; one batch of up to 8 frames finishes before cancellation unwinds. ffmpeg children are killed immediately.
4. **Import screen still has no Cancel/ETA control.** `static/studio/import.js` is not owned. The job message now carries “estimating / about N s left / N s so far” and `shell.js` renders it; `check.js` adds Cancel reading on its “still being read” card.
5. **Check ETA is client-side.** `routes_check.py` is not owned, so no server `eta` field exists. `check.js` measures the rate from its 1.8 s polls, hides the number before 10%, and falls back to elapsed + stage.
6. **Explicit `en` is indistinguishable from the settings default `en`.** `_speech_language` treats plain `en` as auto, so English still detects correctly and Apple is skipped in favour of Whisper. Explicit `zh`, `es`, etc. are preserved.
7. **Tiny path stubs keep the conservative reserve.** A path source below 1 KiB is treated as unmeasurable and keeps the old guard; real video files do not.
