# Wave 1 — T2 Audio split + dead engines

**Branch:** `rv/w1-t2-audio-split`
**Base:** `wave-1-base` (`2ab7ab3`)
**Scope:** WORKPLAN §3, T2.

## What was built

### Phase A — pure move

`audio.py` was split without behavior change:

| File | Owns |
|---|---|
| `stt.py` | Cloud STT provider list and credential helpers (`openai_key`, `groq_key`, `deepgram_key`, `cloud_stt_key`). No local engine and no network call. |
| `tts.py` | Voice listing, TTS route candidates, every voice adapter, `synthesize_line`, `voice_sample`. |
| `music.py` | Music library listing/moods/pick/resolve, MiniMax and Lyria generation, generated-asset licensing, `beat_grid`, `snap_clips`. |
| `audio.py` | Remains the public facade and owns the mixer, `AudioPlan`, translation, separation, rewrite, caches and envelopes. Re-exports every moved name at the bottom. |

Moved functions call back through `audio.*`, so existing callers and tests that
monkeypatch `audio.CACHE`, `audio._run`, `audio.MUSIC_DIRS`, `audio.VOICE_DIRS`
or `audio.synthesize_line` keep the same behavior.

### Phase B — dead-engine removal

Removed:

- Marian (`_translate_marian`, provider row, readiness probe, dispatch).
- Argos (`argos_pair_ready`, `_translate_argos`, provider row, readiness probe, dispatch).
- Ollama (`_ollama_workflow_text`, `_translate_ollama` call site, rewrite and translation rows, `VIBECUT_LLM_URL` paths).
- `local-mlx` (`_mlx_text`, `_rewrite_mlx`, `mlx_lm_available`, status and rewrite rows).
- MusicGen and Stable Audio detection, status rows, generation dispatch and worker calls.
- The `cc0` bucket from `MUSIC_DIRS`, status, and asset counts.
- `tools/musicgen_generate.py`, `tools/music_generate.py`, `tools/rewrite_mlx.py`, `requirements-music.txt`.

`generate_music` now accepts only MiniMax, OpenRouter Lyria, and the
library/upload bed path. An unknown local descriptor raises `AudioError`
instead of spawning a worker.

## Known gaps — unowned files for Claude Code / Wave 2

These files still mention or call removed engines. T2 did not edit them.

1. `app.py`
   - `/api/audio/music` and `/api/audio/beats` still default `source="cc0"`.
   - `_install_argos_safe()` still calls `audio.install_argos()` and
     `audio.ensure_argos_pair()`. Those functions did not exist before this
     branch either; the route is already dead.
   - Startup/engine routes need the `cc0` default removed.
2. `workflow_config.py`
   - `TEXT_PROVIDERS` still lists `local-mlx` and `ollama`.
   - Default translate/hook routes still list `ollama`.
   - Runtime now ignores those routes, but admin still offers them.
3. `admin/catalog.py`, `admin/routes.py`, `static/admin.js`
   - Provider catalog still fetches/labels `local-mlx` and `ollama`.
4. `static/app.js`
   - Still offers `cc0` and local music labels; `engine_status` no longer
     returns those rows, so they should disappear from pickers but the stale
     labels and filters remain.
5. `cli.py`
   - `--translate-provider` still accepts `argos`, `marian`, `ollama`.
   - `--music` still accepts `cc0`, `stable-small`, `stable-1.0`,
     `musicgen-small`.
6. `README.md`, `docs/shared/audio-replacement.md`, `docs/shared/local-models.md`,
   `docs/shared/licensing.md`
   - Engine tables still describe removed engines.
7. STT request code still lives in `pipeline.py`. `stt.py` is intentionally only
   the cloud credential seam in Wave 1; Wave 2 E1 moves `_cloud_speech`,
   `transcribe_cloud` and related helpers.
8. `tests/test_artifacts.py` and `tests/test_workflow_routes.py` still use
   `"cc0"` inside fixture dictionaries. They pass because `resolve_music_track`
   treats an unknown source as `None`; no production path is exercised.
9. Apple rewrite has no implementation in this codebase. The `apple` route is
   retained in configuration but falls through to the rules fallback, as it did
   when the MLX worker was absent.
