## What was built

### Music (`music.py`)

- `build_brief(text, seconds, moods, genre, bpm_range, energy)` returns the
  editable four-field brief from REVAMP §8.2: mood, energy curve, genre, tempo.
  `instrumental` is always true and `duration` is story length + 4 s tail.
- `brief_hash` / `generation_cache_key(provider, model, brief, seed)` are the
  cache identity from §8.2 step 4. `generate_music` now accepts `seed` and
  `brief_hash`, so the same brief at a new seed is a new cache entry.
- `generate_candidates(brief, routes, count=2)` starts two seeded candidates in
  parallel. A provider failure is returned on that candidate; the call raises
  only when every candidate failed. `generation_available()` hides cloud
  routes without a usable key.
- `lock_track(path, job_dir, ...)` copies the chosen bed into
  `audio/music/<hash>-<name>`, records the SHA-256 and appends to
  `audio/music-lock.json`. `locked_history` and `resolve_locked_track` keep
  regenerated history and verify the hash before reuse.
- `music_json(...)` writes the §8.5 payload: source type, file hash,
  licence/attestation, provider metadata, brief, BPM, in/out points, lock flag,
  loop/fade and duck settings. `build_bed` writes `audio/music.json` for every
  licensed bed.
- `fit_plan(...)` aligns the start to a downbeat, loops a short source on whole
  bars, trims to story length, and applies a 1.5 s fade. `_music_loop` now uses
  it, so trim/loop/fade behaviour is shared by library, upload and generated
  beds.
- Music API (router included from `app.py` with import/include lines only):
  - `GET /api/jobs/{job_id}/music/brief?target=30`
  - `POST /api/jobs/{job_id}/music/candidates`
  - `GET /api/jobs/{job_id}/music/candidates/{index}`
  - `POST /api/jobs/{job_id}/music/lock`
  - `GET /api/jobs/{job_id}/music/locked`

### AudioPlan and mix (`audio.py`)

- `AUDIO_MODES` is the §8.4 set: `original`, `original_bed`, `voice_over`,
  `dub`, `music_only`. Legacy `keep`/`bed`/`voice`/`full` plans still work.
- `normalize_audio_plan` fills ducking and loudness defaults.
  `plan_from_edit` adapts an Edit `audio` object, maps `file_hash` to the locked
  track resolver, and is ready for the W3 T1 story-render wiring.
- `build_bed` now handles all five modes:
  - `original_bed`: original speech keys the sidechain, bed ducks under it;
  - `voice_over`: TTS plus new bed, with the original also ducked under the
    voice when a new bed is chosen;
  - `dub`: translated TTS, original speech ducked, new bed and original both
    ducked under the dub, or Demucs instrumental when
    `music.remove_original` is set and the Separation Pack is installed;
  - `music_only`: no voice, full bed, no ducking.
- Ducking defaults are §8.5: −12 dB, 150 ms attack, 400 ms release.
  `duck_filter` solves the `sidechaincompress` ratio for the requested depth.
- Final `loudnorm` is configurable and defaults to −14 LUFS integrated,
  −1.5 dBTP, LRA 11. The Applied values are stored in `audio_plan["_loudness"]`.
- Voice tracks are padded to story length before the sidechain, so the ducked
  bed does not end when the last spoken line ends.
- `speech_spans` and `speech_band_snr` measure 300–3400 Hz voice-over-music SNR
  over speech spans and store `audio_plan["_speech_snr_db"]`.
  `measure_loudness` returns integrated LUFS and true peak for acceptance runs.
- `_shorten_dub_line` asks the AI text route for one complete short sentence
  with a measured character target, validates the estimate against the
  0.90–1.15× band, retries once, and falls back to a punctuation-aware trim.
  `build_bed` re-synthesises only overlong dub/VO lines, up to three passes,
  and reverts an overshooting rewrite. `audio_plan["_slot_fit"]` and
  `audio_plan["_slot_lines"]` report the result.

### Dub fit (`tts.py`)

- `SLOT_MIN_RATE=0.90`, `SLOT_MAX_RATE=1.15`.
- `plan_slot_fit(native, slot)` returns `fit` / `shorten` / `pad`, tempo inside
  the band, and overflow seconds. `fit_dub_lines` attaches the decision and can
  call Shorten. `slot_fit_summary` reports the percentage.
- `shorten_text_for_slot` is the deterministic fallback. `_voice_track` now
  never exceeds 1.15× (the old path allowed 1.35×) and trims at the slot edge.

### Pack discovery (`packs.py`, `stt.py`, `tts.py`)

- `packs.installed_dir`, `find_asset`, `find_dir` and `find_command` search the
  installed pack first, including flat, `bin/` and `runtime/bin/` layouts.
- `stt._whisper_binary` checks `packs.pack_dir("speech")` before
  `shutil.which("mlx_whisper")`; `_whisper_command` adds the Python-module
  fallback. `_engine_ready` uses the same lookup.
- `tts.kokoro_model_dir` checks `packs.pack_dir("voice")` for
  `models/kokoro`, `kokoro` or the pack root before `data/models/kokoro`.
  `audio.kokoro_available` uses the same order.
- `audio.demucs_available` / `separate_vocals` also accept a Separation Pack
  `demucs` command.

## Known gaps

1. **Cloud music is unavailable in this environment.** OpenRouter Lyria
   returned 401 and no MiniMax key exists. The request/cache/licence path is
   tested with fakes; library/upload is the only live bed path.
2. **Kokoro Voice Pack is not installed here.** The live dub used Apple `say`
   Tingting. Pack-first model lookup is covered by a fake installed pack.
3. **Separation Pack is not installed here.** “Remove original voice” uses
   Demucs only when the pack/module is present; otherwise dub falls back to
   ducking, as REVAMP §8.6 allows.
4. **BPM can be null.** `music.json` always has the BPM field, but a generated
   pad with no detectable beat grid reports `bpm_source: "unavailable"`.
   Real library tracks get the librosa grid.
5. **Shorten needs the AI text route for best quality.** The deterministic
   fallback keeps a punctuation boundary but can still read as a clipped
   clause when every text provider is unavailable.
6. **Voice Pack Python runtime is not added to `sys.path`.** The model
   directory and `mlx_whisper` binary are discovered from the pack; a pack that
   ships `kokoro_onnx` only inside its own site-packages still needs the module
   installed in the app runtime (W5 packaging).
7. **`plan_from_edit` does not carry a translate target.** The Edit `audio`
   schema does not include `translate`; W3 T1 must pass the story's target
   language alongside the Edit.
8. **No Studio work.** T3 owns no `static/studio/**` file; the T4 audio layer
   consumes the endpoints above.
9. **Candidate preview is a backend helper only.** `music.preview_candidate`
    renders a ducked A/B preview, but the UI preview control belongs to W3 T4.
10. **Library attestation is caller-supplied.** A library track without a
    `.license.json` sidecar (or `music.licence` in the plan) reports
    `licence.type: "unknown"`; `VIBECUT_AUDIO_LICENSE=strict` refuses it. The
    attestation UI is a later flow/Setup owner.
