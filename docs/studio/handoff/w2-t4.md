## What was built

1. **`static/studio/edit/index.js` — editor shell.**
   - Opens one story and one aspect at a time from the existing clip set.
   - Story picker, 9:16 / 4:5 switch, Undo, save status and plain empty states.
   - Loads `GET …/edits/current`; creates the Edit with `POST …/edits` when absent.
   - Autosaves through `PATCH …/edits/{edit_id}` in 450 ms batches.
   - A 409 reloads the current head, keeps local unsaved layer fields, then retries once. A second 409 leaves the change visible and reports it.
   - 4:5 forks the current 9:16 layers on first creation, then diverges.
   - Flushes the save before story/aspect changes and on page hide.
2. **`static/studio/edit/preview.js` — live canvas + safe zones.**
   - 1080×1920 / 1080×1350 canvas, letterboxed media, responsive size.
   - Draws dashed safe area and advisory top/bottom/button chrome for both aspects.
   - Consumes `GET /api/jobs/{job_id}/edits/{edit_id}/frame?t=<seconds>&quality=draft`.
     - `200` image/jpeg draws the exact frame.
     - `409` asks the editor to reload the head and retry.
     - `422` reports that this time has no frame.
     - `404` / missing route falls back to the proxy.
   - Tries `GET /api/jobs/{job_id}/edits/{edit_id}/proxy` for playback and scrubbing.
     - If the proxy is missing too, the canvas shows a quiet placeholder; every control still saves.
   - Exact frame when paused, fast preview while playing/scrubbing when the proxy is available.
   - Selected text/caption box is outlined on the canvas.
3. **`static/studio/edit/timeline.js` — sentence + layer tracks.**
   - Sentence lane built from story clips in output order, with source sentence text and hook/beat/payoff roles.
   - Clean / Text / Captions / Effects / Color / Audio lanes.
   - Positions are percentages, so no horizontal scrolling at 1280 or 1440.
   - Click and drag seek; bars select and seek; ruler ticks and keyboard arrows/Home/End seek.
4. **`static/studio/edit/layers/text.js` — real text layer controls.**
   - Add hook card, title, lower third, end card or key word.
   - Edit text, kind, start/end, anchor, width/height, font, size, weight, colours, background, alignment, uppercase, shadow, opacity and safe-area flag.
   - Removes a text layer.
   - Writes `graphics[]` text entries only; no invented fields.
5. **`static/studio/edit/layers/captions.js` — caption track + style controls.**
   - Builds a story caption track through `POST /api/jobs/{id}/captions` with `set_id`, `story_id` and a style preset.
   - Lines are editable (text, start, end) and saved through `PATCH /api/jobs/{id}/captions/{track_id}`.
   - Style controls: preset, size, text colour, outline colour/width, position, max characters, max lines, background colour/fill, uppercase, safe top/bottom.
   - The Edit caption pointer is updated to the returned track id; `enabled` is stored in the Edit.
   - Attaches an existing story caption track automatically when the Edit has none.
6. **`static/studio/edit/layers/color.js` — colour presets and sliders.**
   - All nine backend presets with labels/swatches.
   - Brightness, contrast, colour, warmth, vignette, grain and sharpness sliders.
   - Writes absolute values matching `edits.normalize_color`; no client-only look state.
7. **`static/studio/edit/inspector.js` — tabs.**
   - Clean, Text, Captions, Effects, Color and Audio tabs with counts.
   - Clean and Effects list existing layers and allow removal.
   - Audio shows the saved mode, duck and loudness targets.
   - Clean/Effects/Audio creation controls are deliberately placeholders for Wave 3 tracks.
8. **`static/studio/edit/model.js` — pure helpers.**
   - Presets, sentence-to-output-time mapping, layer spans, anchor geometry, safe-zone rectangles, time formatting, 4:5 canvas sizes.
9. **`static/studio/edit/api.js` — route wrappers.**
   - Existing Edit CRUD, caption track, frame and proxy paths only.
   - Adds the same read cookie as Studio for `<video>` / image media.
10. **`static/studio/edit/edit.css` — scoped editor styles.**
    - Only under `.st-edit-panel` / editor classes; no changes to `studio.css`.
    - Focus-visible states inherited from the shell plus input focus rings.
    - Responsive: two columns at 1280/1440; inspector stacks below the preview under 1040 px.

## API usage

| Method | Path | Use |
|---|---|---|
| `GET` | `/api/jobs/{job_id}` | Open the video and its story caption pointers |
| `GET` | `/api/jobs/{job_id}/clip-sets` | Story list and story clips |
| `GET` | `/api/jobs/{job_id}/edits/current?set_id&story_id&aspect` | Load the current Edit (404 = none) |
| `POST` | `/api/jobs/{job_id}/edits` | Create the first Edit / 4:5 fork |
| `PATCH` | `/api/jobs/{job_id}/edits/{edit_id}` | Save layers; 409 reload-and-retry |
| `POST` | `/api/jobs/{job_id}/edits/{edit_id}/undo` | Undo creates a new head |
| `GET` | `/api/jobs/{job_id}/edits/{edit_id}/frame?t&quality=draft` | Exact preview frame |
| `GET` | `/api/jobs/{job_id}/edits/{edit_id}/proxy` | 540p scrub/playback fallback |
| `GET` | `/api/jobs/{job_id}/captions/{track_id}` | Load the caption track |
| `POST` | `/api/jobs/{job_id}/captions` | Build a story caption track |
| `PATCH` | `/api/jobs/{job_id}/captions/{track_id}` | Save caption style and cue text |

`DELETE …/edits/{edit_id}` is intentionally not called: this base has no reset action, and the API contract is that DELETE only clears the pointer.

## Contract notes

- The frame and proxy routes are owned by Wave 2 T1 and are not present on `wave-2-base`. The editor codes against the stated contract:
  - frame `404` unknown, `409` stale, `422` bad `t`, success `image/jpeg`;
  - proxy is a 540p `video/mp4`.
- On base, the frame request returns `404`, the proxy element errors, and the canvas falls back to the placeholder without blocking edits. The source badge reads “Preview not ready”.
- No new endpoints and no network calls beyond the local server.

## Known gaps

1. **Integration blocker (unowned file).** `static/studio/shell.js` imports `./edit.js`, which is the Wave-1 placeholder and is outside Track T4 ownership (`static/studio/edit/**`). `static/studio/edit/index.js` exports `mount(root, ctx)` with the same signature. To make Edit reachable, a principal/reviewer change is needed:
   - either change the shell import to `./edit/index.js`, or
   - replace `static/studio/edit.js` with `export { mount } from "./edit/index.js";`.
   I did not edit that file because the hard rule says unowned files must not be touched. Until that one-line wiring lands, the new editor is complete but hidden behind the old placeholder.
2. **Frame/proxy are Wave 2 T1.** On this branch the routes return 404. Exact frames and 540p scrubbing start working when T1 merges; the fallback path is already exercised.
3. **Clean / Effects / Audio creation controls** are placeholders by track scope. Their lanes, existing items, removal actions and saved summaries are live; Wave 3 owns their full panels.
4. **Sentence editing** is a display/seek lane in this base. Trim/reorder/exclude needs the story-edit route and belongs to the next layer work.
5. **Caption word confidence / unsure-word navigation** is not shown; the current caption API exposes cues, not word confidence. That arrives with the STT track.
6. **No automated JS test** was added because Track T4 owns no `tests/` file. The manual headless checks above cover mount, write, 4:5 fork, caption save and stale-head retry. The suite stays at the 1004 baseline.
7. **Colour preview while the proxy is used** applies an approximate canvas filter. Exact frames always show the server’s compiled colour; the proxy is a scrub aid.
