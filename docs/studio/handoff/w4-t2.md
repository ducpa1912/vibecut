## What was built

### 1. Inline Edit preflight endpoint

```http
GET /api/jobs/{job_id}/edits/{edit_id}/preflight
```

Response:

```json
{
  "markers": [
    {
      "t": 2.0,
      "end": 5.0,
      "kind": "collision",
      "severity": "warn",
      "message": "Hook tx01 overlaps Title tx02 (100% of the smaller layer).",
      "layer_id": "tx01"
    }
  ],
  "pass": false
}
```

- `t` and `end` are output-timeline seconds.
- `layer_id` is present only when one layer owns the marker.
- `pass` is false when any marker is `warn` or `block`. An unavailable advisory
  check is `info` and does not fail the pass.
- Unknown job/Edit: 404. Analysis not ready or Edit story missing: 409 JSON.
  Compile failure: 422 JSON. The route keeps FastAPI's `detail` shape.

Marker kinds:

| `kind` | What it measures |
|---|---|
| `collision` | Two text/graphic/caption layers occupy the same pixels at the same time (≥12% of the smaller layer). |
| `face_overlap` | An overlay or a `blur`/`plate`/`mask` Clean layer covers a Check face. Faces are mapped through the segment crop. |
| `safe_zone` | An overlay is outside the safe area, or inside platform chrome, for 9:16. |
| `aspect_4_5` | The 4:5-specific platform-chrome result. 4:5 chrome hits use this kind instead of `safe_zone`. |
| `residual_text` | OCR text survives inside a Clean layer, or the latest Check report has baked subtitle/title/lower-third/credit text that no active Clean layer covers. |
| `caption_density` | A caption cue is over 20 characters per second. |
| `loudness` | A measured render is outside −16…−12 LUFS, or the Edit's target is outside that window. |
| `voice_fit` | A voice line is outside the 0.90–1.15× slot band, a voice rate is outside it, or the stored summary reports flagged lines. |
| `missing_music_license` | A music bed has no licence note, or CC has no attribution text. |

Residual and loudness are evidence-based where evidence exists. The route
compiles the Edit with its caption track, so collision, safe-zone, caption
density and face mapping use the real layer rectangles.

### 2. Residual route hardening

`POST /api/jobs/{id}/cleanup/residual` now shares
`routes_cleanup.measure_residual()` with preflight.

- **Hard cap:** `cleanup.RESIDUAL_MAX_FRAMES = 60`. A larger `max_frames`
  returns `422` with `"max_frames is capped at 60 frames per request."`
  `times` is also capped at 60 values. The default is 30.
- **Per-request deadline:** `cleanup.RESIDUAL_TIMEOUT_SECONDS = 240`. The
  deadline is checked before every frame; expiry returns `504` with a reason.
- **Clear JSON on failure:** expected body failures are 4xx. A render or OCR
  failure is `500` with `"Residual render failed: <type>: <reason>"`, a
  logged traceback, and the partial temp directory removed. Unexpected route
  failures are also `500` JSON, never an HTML 500.
- **Preflight residual:** 24 frames at 0.5 fps, draft quality, 90 s budget.
  A residual error becomes an `info` `residual_text` marker; it never turns
  the preflight request into a 500 and does not fail the pass by itself.
- **Coverage marker:** the preflight also reads the stored Check report and
  marks baked text with no active Clean layer (for example after a layer is
  deleted). Screen text, watermarks and handles are excluded from that check.

### 3. Clean layer provenance + save gate

Clean layers may now carry two optional fields:

```json
{
  "kind": "plate",
  "box": {"x": 0.1, "y": 0.7, "w": 0.8, "h": 0.2},
  "tracklet_id": "trk_0001",
  "tracklet_kind": "subtitle"
}
```

`kind` was already the Clean **method** (`crop_guard`, `blur`, `plate`,
`mask`), so the detected Check kind is stored as `tracklet_kind`.
`cleanup.tracklet_clean_layers()` now emits both fields, including for the
companion plate under a mid-frame blur.

On every Edit save (create, patch, undo, restore), `routes_edits` re-runs
`detect.cleanup_block_reason(kind, attested)` for every layer that names a
kind:

- `watermark` → 409, refused;
- `screen_text` → 409, refused;
- `handle_or_logo` → 409 unless `job["rights"]` is attested;
- every other named kind → 409 while rights are unattested.

A layer with only `tracklet_id` resolves its kind from the stored Check
report. Old Edits have neither field and keep the same hash. The fields are
omitted when absent, so old Edit bytes and hashes do not move.

## Known gaps

- **No Studio UI in T2.** The marker API is ready for T4. T2 did not touch
  `static/studio/**`.
- **Existing Studio Clean does not send provenance yet.** `clean.js` builds
  layers without `tracklet_id`/`tracklet_kind`; those layers still save under
  the Wave 3 rights gate. The new kind gate applies when provenance is present
  or when a `tracklet_id` resolves in the Check report. T4 or a later Clean
  owner must write the two fields from `/cleanup/layers`.
- **Residual sampling is sparse in preflight.** 24 draft frames at 0.5 fps
  can miss a one-frame ghost. The final `/cleanup/residual` run remains the
  acceptance measurement.
- **Hard cap changes the old route.** Long sources must use `start`/`end` or
  an explicit `times` list; `max_frames` above 60 is refused. This is the
  intended Wave 4 protection for the founder's 60-frame failure.
- **Deadline is checked between frames.** A single frame render is bounded by
  `render` but can overshoot the remaining budget by one frame.
- **Loudness needs a render.** It measures media only when a render record
  carries the exact `edit_hash` or `edit_id`. Before a render it checks the
  Edit target only, so it cannot detect a mix that misses its target until a
  render exists.
- **Voice-fit needs stored line data.** T3's runtime `_slot_fit` summary is
  not persisted in the Edit today. Preflight uses `audio.voice.fit` /
  `lines[].fit`, `native`+`slot`, the summary if present, or the chosen rate.
- **Uncovered-text marker is plan-level.** It reads the latest Check report
  and can warn about text the creator intentionally leaves. It excludes
  screen text, watermarks and handles.
- **4:5 zones are advisory.** They use the shared `overlays.SAFE_AREAS` and
  `RESERVED_ZONES` constants, not a platform guarantee.
- **Residual OCR unavailable.** The marker becomes `info`, and `pass` is not
  failed by that alone.
- **No founder-video live run in this track.** The synthetic smoke only
  proves the real ffmpeg route path.

## Founder manual test

Setup: open the job in Studio, use the **Import → own-footage attestation**
control, then finish **Check**. For the marker read, open a browser tab and
paste the preflight URL for the current job and Edit into the address bar.
For the Clean-gate probe, run the command below from a terminal in the repo
root; `$JOB` and `$EDIT` are the ids shown in the Studio URL and job folder.

```bash
BASE=http://127.0.0.1:8787
# Watermark probe: must be 409, "Watermark removal is not supported..."
curl -s -o - -w '\n%{http_code}\n' -X PATCH \
  "$BASE/api/jobs/$JOB/edits/$EDIT" \
  -H 'Content-Type: application/json' \
  -d '{"clean":[{"kind":"plate","box":{"x":0.8,"y":0.05,"w":0.15,"h":0.06},"tracklet_id":"probe_water","tracklet_kind":"watermark"}]}'
```
