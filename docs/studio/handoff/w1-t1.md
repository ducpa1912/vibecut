## What was built

1. **`edits.py` — versioned Edit document (schema 1).**
   - Immutable sidecars at `jobs/<job_id>/edits/<edit_id>.json`.
   - Pointer at `job["story_edits"]["{set_id}:{story_id}:{aspect}"] -> edit_id`.
   - Every write is a new version: `version + 1`, `parent` = previous edit id.
   - Content hash is sha256 over canonical JSON (sorted keys, no whitespace, UTF-8), like `overlays.overlay_hash`.
   - Hash covers every layer and every asset reference (LUT, sticker, music, voice) plus `renderer_version`.
   - `id` covers content hash + version + parent, so identical content restored at the same position is idempotent and a new position is a new id.
   - `history_store` entries use `type: "edit"`, `id` = edit id, `record_key` = story key and a full snapshot. Undo and restore append a new version; old versions are never rewritten.
   - `normalize_edit` verifies both the stored hash and id, so a tampered sidecar is rejected.
2. **`routes_edits.py` — CRUD and version API.**
   - Validates the owned job, clip set, story, aspect and caption-track reference.
   - Rejects stale clip sets and changed story clip hashes with `409`.
   - `PATCH` only edits the current head; `undo`/`restore` create a new head.
   - `DELETE` removes every version for that story/aspect plus their history entries and clears the pointer (explicit delete policy).
   - `compile` returns the pure compiler output for previews; no render is queued.
3. **`compose_render.py` — pure Edit compiler.**
   - Makes no ffmpeg or network call and writes no file.
   - Emits per-segment `pre_filter` (clean), `crop_filter`, `scale_filter`, `post_filter` (motion + colour) and a full `filter` string, plus a flat output-coordinate overlay list.
   - Clean boxes use source coordinates and render before crop; graphics/captions use output coordinates; motion compiles after scale as a `zoompan` crop window.
   - `crop_guard` shifts the static crop window to clear the guard box, with a deterministic `crop_guard_unmet` warning when impossible.
   - Colour compiles eight named presets plus optional LUT and sliders to `eq`, `colortemperature`, `vignette`, `noise` and `unsharp`.
   - Captions compile from a supplied caption track into overlay layers; a missing track produces a warning in the pure compiler and a `409` in the API.
4. **Tests.**
   - `tests/test_edits.py`: model defaults, canonical hash, immutability, pointer helpers, history compatibility, version chain, restore, all CRUD/version routes, owned-reference validation, aspect forks.
   - `tests/test_compose_render.py`: golden filter strings for plate, blur, motion kinds, colour and full composition; coordinate rules; crop guard; caption layers; determinism; source-size fallback; proof that no process is started.

## Edit schema (schema 1)

```text
Edit
  schema_version     1
  renderer_version   int, part of the content hash
  id                 ed_<32 hex>       id over hash + version + parent
  version            int >= 1
  parent             ed_<32 hex> | null
  hash               edh_<32 hex>      sha256(canonical JSON)
  created            epoch seconds
  story_ref          {set_id, story_id, clip_hash, title, duration, clip_count}
  aspect             "9:16" | "4:5"
  clean[]            {id, kind: crop_guard|blur|plate|mask, box(source x/y/w/h),
                      ranges[{start,end}], z, color, opacity, radius, label}
  reframe            {mode: auto|center|manual, cx, cy, zoom,
                      crop_path_ref, overrides{cx?,cy?,zoom?}}
  motion[]           {id, kind: punch_in|snap_zoom|push|shake,
                      start, end, amount, ramp, seed}
  color              {preset, lut{path,hash}|null, exposure, contrast,
                      saturation, temperature, vignette, grain, sharpen}
  graphics[]         text: {id, type:"text", kind: hook|title|lower_third|cta|emphasis,
                             text, start, end, anchor, box, z, style, safe_zone, opacity}
                     fx:   {id, type:"fx", kind: arrow|circle|underline|progress_bar|sticker,
                             start, end, anchor, box, z, color, thickness, opacity, asset}
  captions           {track_id, style_id, enabled}
  audio              {mode: original|original_bed|voice_over|dub|music_only,
                      duck_db, loudness{lufs,true_peak}, music?, voice?}
```

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/jobs/{job_id}/edits` | List summaries; optional `set_id`, `story_id`, `aspect` filter; returns pointers |
| `GET` | `/api/jobs/{job_id}/edits/current` | Current edit for `set_id`, `story_id`, `aspect` |
| `POST` | `/api/jobs/{job_id}/edits` | Create or update the story/aspect edit (new version on change) |
| `GET` | `/api/jobs/{job_id}/edits/{edit_id}` | Read one immutable version |
| `PATCH` | `/api/jobs/{job_id}/edits/{edit_id}` | Edit the current head; creates a new version |
| `GET` | `/api/jobs/{job_id}/edits/{edit_id}/versions` | Parent chain oldest first plus current pointer |
| `POST` | `/api/jobs/{job_id}/edits/{edit_id}/undo` | Restore the parent content as a new head |
| `POST` | `/api/jobs/{job_id}/edits/{edit_id}/restore` | Restore `{version}` or `{history_entry}` as a new head |
| `DELETE` | `/api/jobs/{job_id}/edits/{edit_id}` | Delete all versions/history for the story/aspect and clear the pointer |
| `GET` | `/api/jobs/{job_id}/edits/{edit_id}/compile` | Pure compiled filters + overlays; `include_captions=false` skips caption layers |

No Studio UI. `app.py` changes are only the `import routes_edits` and `app.include_router(routes_edits.router)` lines.

## Compiler output

```text
compile_edit(edit, clips=..., source=..., scenes=..., caption_track=...)
  segments[]  index, scene, start, end, duration, frames, out_start, out_end,
              crop{x,y,w,h}, crop_path_ref, clean_ids[], motion_ids[],
              pre_filters[], pre_filter, crop_filter, scale_filter,
              post_filters[], post_filter, filter
  overlays[]  id, type (text|fx|caption), kind, text?, start, end, duration,
              box, rect (output coordinates), z, style/color/thickness,
              opacity, safe_zone, asset?
  captions    track_id, style_id, enabled, cue_count, compiled
  warnings[]  code, message, segment? / layer_id? / track_id?
  counts      segments, overlays, clean, motion
```

The chain is `[clean] -> crop -> scale -> setsar -> fps -> format -> [motion] -> [colour]`, matching REVAMP_PLAN §4. The renderer still owns fades, caching, concat, audio and muxing.

## Never-list enforcement

The model rejects `inpaint`, `generative`, `delogo`, watermark-removal intent, voice-cloning intent, avatars and stock B-roll in clean labels/ids. Clean kinds are restricted to `crop_guard|blur|plate|mask`; graphics to the fixed catalogue; audio modes to the five supported plans. No engine, model pack or network call is used.

## Known gaps

- **Wave 2 T1** must wire `pre_filter` / `post_filter` into `render._segment`, add the cache-key hashes, implement the frame endpoint, rasterize overlay layers to PNG/PNG sequences and resolve `reframe.crop_path_ref`. This branch does not call `render.py`.
- Motion is compiled as `zoompan` after the output scale. A motion layer that spans a cut restarts its ramp at the next segment; continuity across segment boundaries is Wave 2 work.
- `crop_path_ref` is stored and passed through but not resolved by the pure compiler; scene crop centres are used for `mode: "auto"`.
- `audio.music` / `audio.voice` accept validated JSON objects but the detailed `AudioPlan` schema is Wave 3 (music/mix/dub). Only `mode`, `duck_db`, loudness targets and optional asset hashes are enforced now.
- Caption word-pop/karaoke are represented only by the caption track/style reference. Per-word animation is Wave 2 T1/Wave 3 UI work.
- Plate/mask compile to solid `drawbox`; feathering, rounded corners and styled plates are later compose work.
- `DELETE` deliberately deletes the whole story/aspect edit document (all versions), because a non-head version always has a child. It is not a per-version delete.
- No migration from legacy `story_captions` into an Edit; that is Wave 4 T3.
- Two writers racing the same story/aspect can save deterministic versions but only the last pointer update wins; per-job job-lock serialisation is not added because the renderer owns the job write lock.
