## What was built

### 1. `static/studio/finish.js` — Finish screen

- **Render 9:16 and 4:5.** A story set, shape and Quality control feed the
  durable story queue. The main action is `Queue all stories · 9:16 / 4:5`;
  each story also has `Queue 9:16` and `Queue 4:5` so both shapes can be
  produced without a second screen.
- **Queue.** Shows recent queues, progress, per-story state and errors. Pause,
  Cancel and Resume use the existing queue action route. A paused queue never
  restarts by itself.
- **Versions.** Ready cuts are grouped per story and shape. Each row shows the
  server's version label, quality and date, and can be selected, kept (pinned)
  or previewed. Two ready versions compare side by side in two video players.
- **Edit history.** The current Edit version chain is listed with a
  `Use this version` action that calls the existing restore route. Restore
  creates a new head; history is not rewritten.
- **Preflight.** Consumes the new marker contract
  `GET /api/jobs/{id}/edits/{edit_id}/preflight` and renders timeline time,
  severity, message and suggestion. If that route is absent (this base), it
  falls back to the merged story-level `GET /api/jobs/{id}/preflight` and says
  that whole-story checks were used.
- **Publish kit.** Builds from one ready cut with three titles, a 125-character
  description, 3–8 hashtags, two cover times and an optional pin comment.
  It first calls the Packet v2 route
  `POST /api/jobs/{id}/artifacts/{artifact_id}/packet`; if that route is absent
  it falls back to `POST /api/jobs/{id}/packets` with `artifact_ids`. Recent
  kits and the ZIP download are listed.
- **Review link.** Creates a link bound to the selected cut, with 7/30/90/no
  expiry and a label. Session links can be copied; open links are listed with
  their real active, expired or revoked state. No token is ever read back.
- **Apply to all stories.** Copies one source story's caption style, text
  style, colour preset, music brief and voice to every other story in the
  same shape. Text and timing stay per story:
  - caption style patches each target's own caption track and then points its
    Edit at the new track;
  - text style copies only the style object, never the source text or times;
  - colour copies the full colour plan;
  - music copies only the brief, never the source track;
  - voice copies engine, voice and rate.
  Stories without an Edit get a new Edit only for the selected style fields.
  Clean layers are never copied.

### 2. `static/studio/setup.js` + shell wiring — Setup screen

- Rail button **Setup** opens a dedicated dialog. It has three sections:
  **Engines**, **Keys** and **Packs**.
- Engines are grouped as On this Mac, Cloud voices and OpenRouter voices.
  HeyGen is listed under **OpenRouter voices** with the
  **free until 30 Nov 2026** hint.
- Keys are password fields for OpenRouter, MiniMax and ElevenLabs. A saved key
  is never returned to the browser; the screen shows only Saved on this Mac,
  From an environment variable, or Not set. Save and remove use
  `POST /api/settings` with `secrets` only.
- Packs shows Speech, Voice and Separation with installed state, size and a
  plain explanation. This base has no pack install/remove HTTP route, so the
  screen reports what is on disk and does not fake a download.

### 3. `static/studio/edit/layers/clean.js` — server auto-fill

- First open of Clean on a story still triggers the Check pre-fill, but the
  saved layers now come from `POST /api/jobs/{id}/cleanup/layers`.
- The browser sends the selected `tracklet_ids` and `include_handles: false`.
  Watermark, screen-text and handle/logo policy is decided by the server (the
  single gate), not by browser code.
- The 32-slot cap is kept and explained: `All 32 cover slots are used. Remove
  one to add another.` The server's refusal count and first warning are shown.
- If Clean is disabled or the route is missing, the panel reports it and does
  not silently build layers in the browser. Manual boxes remain available.

### 4. `static/studio/edit/layers/audio.js` — music candidates and voices

- Reads the brief with `GET /api/jobs/{id}/music/brief`, shows the four plain
  fields (Mood, Energy, Genre, Tempo) and lets the creator change them. The raw
  prompt is derived, not edited.
- Generates two candidates with `POST /api/jobs/{id}/music/candidates`.
  Candidate A and B each have a preview button wired to
  `GET /api/jobs/{id}/music/candidates/{index}`, and a `Use A / Use B` action
  that locks the bed with `POST /api/jobs/{id}/music/lock`.
- `GET /api/jobs/{id}/music/locked` lists locked beds so a story can reuse one.
- Library tracks and uploads remain offline paths.
- When no cloud music engine is available, the panel shows
  `Cloud generation needs a MiniMax or OpenRouter key.`
- The voice picker labels HeyGen as
  `HeyGen Voice Turbo · free until 30 Nov 2026` and repeats the hint under the
  picker when HeyGen is selected.

## Known gaps

1. **Packet v2 and edit preflight are not on `wave-4-base`.** Finish codes
   against both routes and falls back to the merged `/packets` and
   `/preflight?story_id=` routes. When W4 T1/T2 merge, the primary routes take
   over without a UI change. The fallback is labelled "whole-story checks".
2. **Pack install/remove has no HTTP route on this base.** Setup reports
   Speech/Voice/Separation state and size but cannot download or remove a
   pack. Pack downloads remain a Mac packaging/W5 item or need an agreed route.
3. **Clean does not store `tracklet_id`/`kind` on the saved layer.** The base
   Edit Clean schema rejects both keys. Auto-fill sends the selected
   `tracklet_ids`; the server applies the kind policy. Storing the metadata on
   the layer still needs the W4 T2/core schema change already listed in the W3
   review (open item 2). Until then a hand-drawn box over a watermark is gated
   by rights, not by kind, after it is saved.
4. **A/B music preview is the raw candidate.** The existing candidate file
   route returns the bed, not a ducked preview mix. The first candidate is
   cached by provider/model/brief/seed, so a second preview costs nothing.
   Ducking is applied when the story renders.
5. **Cloud music and cloud voice were not exercised live.** The environment
   had no MiniMax or OpenRouter key. The no-key message and the local library
   path were checked.
6. **Speech Pack detection uses cached Whisper models.** If a pack is
   installed but no model cache is visible, Setup says Not installed. The
   pack module has no status route to ask.
7. **Apply to all only copies text style onto text layers that already
   exist.** It does not invent a new hook on a story that has no text. This is
   deliberate: text and timing stay per story.
8. **Apply caption style needs the target story to have captions.** A target
   with no caption track is counted as skipped, not given auto-captions.
9. **Finish uses `POST /api/story-queues` and does not call the one-story
   render route directly.** Per-story buttons queue one item, so the same
   durable queue and recovery path is used for every render.
10. **No founder video was used in this wave.** The W3 live checklist still
    applies for the final visual approval.
