## What was built

- Native ES-module Studio app under `static/studio/`, no build step, no new backend routes.
- Five-step left rail: **Import · Check · Stories · Edit · Finish**.
- **Import** works on the existing ingest routes: upload, local path, link, and recent videos. A rights attestation is required before any import starts.
- **Stories** works on the existing job, clip-set, story-render and story-queue routes: job status polling, story-set build, story cards, per-story render, and queue-all.
- **Check / Edit / Finish** are honest placeholders that keep the step map visible.
- Settings → **Use Classic editor** saves `vibecut.editor = "classic"` in `localStorage` and opens the Classic page. The Classic header gains an **Open Studio** link that saves `"studio"` back.
- Studio is the default entry point. Classic markup, `static/app.js` and `static/creator.js` are unchanged. The Classic scripts load only when Classic is chosen, so Studio does not start the old app underneath its overlay.
- Plain-language copy; no “v1/v2”, “flow”, “artifact”, “matrix” or “plan” in Studio UI.
- Scoped Studio CSS with visible focus rings, labelled controls, `role="status"`/`role="alert"` messages, tab keyboard support, `dialog` settings, reduced-motion handling, and layouts verified at 1280 and 1440.

## Known gaps

1. **Rights attestation is client-side only.** No import-attestation field exists in the backend this wave. `import.js` records the accepted value in `localStorage` and exports `hasAttestation(jobId)`. The Clean backend must enforce and persist this in Wave 3; until then it is a UI gate, not a server gate.
2. **Check / Edit / Finish are placeholders.** They show the intended scope and return to the working steps.
3. **No render progress in Stories.** Per-story render and queue-all start through the real routes; following queue items through to ready belongs to Finish.
4. **No caption-track choice at render time.** Story renders use the server defaults (captions on, current track).
5. **Multi-item links** return the server’s “choose one entry” message as an error; there is no link picker in Wave 1.
6. **No native path browser.** The Path tab accepts a typed absolute path; Browsers cannot open a local file picker for a path.
7. **No upload cancel.** Navigating away does not abort an in-flight XHR upload.
8. **Classic loads on demand.** The old scripts start after `DOMContentLoaded` when Classic is selected, instead of in parallel with the first page paint. This keeps Studio free of the old app’s startup requests; Classic behaviour is otherwise unchanged.
9. **Status wording for unknown states** falls back to title case; only the current server states are mapped.
10. **No automated browser test was committed.** Track ownership lists no test file for Studio; verification above was run manually in headless Chrome against a temporary data directory.
