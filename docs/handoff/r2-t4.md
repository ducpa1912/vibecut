# R2 T4 — Acceptance + browser tests

**Branch:** `rv/r2-t4-acceptance`

**Base:** `refactor-2-base` (`d5d7590`)

**Scope:** `docs/R2_TRIM_PLAN.md` §3 T4 — the round_5 “Tests required” list, a synthetic trim job, and the mounted Studio drag.

## What was built

- `tests/test_trim_acceptance.py` — route-level acceptance against the frozen §2 contract:
  - start trim later and earlier, with layer/time mapping through the clips;
  - fully outside layers kept as `hidden: true` with a receipt entry;
  - partially outside layers clipped, inside layers moved;
  - caption track rebuilt (new id, new `clip_hash`, cue times follow, manual fix kept);
  - cached caption track rejected after a clip change;
  - burn cues, SRT and packet SRT all carry the same cue times/text;
  - atomic failure on caption reflow, Edit build and the single commit;
  - initial range → dry run with zero writes;
  - stale revision, two trims, Stories patch then Edit save, and a 409 `edit_stale` from Finish;
  - multi-aspect rebind with an immutable old artifact;
  - explicit `/rebind` repairs both stale aspects after a story clip change;
  - undo restores range, layer times and caption track as a new Edit version;
  - undo with a token from an older trim returns 409.
- `tests/fixtures/trim_job/trim_fixture.py` — deterministic synthetic job: 40 four-second scenes, one unique transcript sentence each, three non-overlapping story ranges, a 24 s middle story, and a browser story at source 0 with a prefix, moved and tail layer.
- `tests/browser/trim_drag.spec.mjs` — Node Playwright 1.64 mounted drag. Drags the real start and end handles, then asserts the header duration, the moved layer bar, the caption cue bar, the tail layer’s outside flag, focus on the start handle, keyboard widen, and that the header and timeline span agree.
- `tests/test_browser_trim.py` — starts uvicorn on a free loopback port with a scratch `VIBECUT_DATA` directory, writes the fixture, runs the spec, and stops the server in `finally` (terminate, then kill after 10 s). Skips when node, Playwright, ffmpeg or the browser is missing; only a spec exit code of 2 is a skip.

Every trim test does `pytest.importorskip("routes_trim")` and `pytest.importorskip("caption_reflow")`. On this branch the two modules are absent, so both files skip; they run after T1/T2 merge.

## Known gaps

- The acceptance assertions cannot execute until T1 (`routes_trim`) and T2 (`caption_reflow`, fail-closed render) merge. They are written against §2, not against a local stub.
- The Edit/commit failure tests patch the contract seams `edits.build_edit` and `app.update_job`. If T1 routes through a private helper with its own reference, those two tests need that reference patched; the atomicity assertion is otherwise the same.
- `invalidated_artifacts` asserts that a ready manifest with the story’s old `edit_hash` is listed. T1 must scan manifests (or the job render records) by story + edit hash.
- The browser spec assumes T3 keeps the Edit header id `#st-edit-meta`, the timeline span id `#st-timeline-span`, handle classes `.st-tl-trim-start` / `.st-tl-trim-end`, bar class `.st-tl-bar`, `data-layer`, `data-start` and `data-outside`. If T3 renames them, update the spec selectors — the behaviours are unchanged.
- The browser test generates a 26 s 1080×1920 synthetic clip so the frame route answers and the preview does not retry; it does not use founder footage.
- No live founder-video run. No A/B compare or approved-version lock (deferred in R2).
- `test_packet_carries_the_trimmed_cues` is skipped when ffmpeg is absent. The other caption/SRT/burn checks still run.

## Founder manual test

Videos: **A** = a 9:16 story with a hook layer and burned captions; **B** = its 4:5 aspect with a lower third.

| Action | Intent | Expected | Result |
|---|---|---|---|
| A: open Edit, note the header time, drag the start handle one sentence later, drop | Start ripple and one duration source | Header, preview, scrubber and timeline show the shorter length. The hook/lower third stays over the same words. Captions follow. No stale badge. | |
| A: drag the start handle back earlier, drop | Both-direction trim over the pool | The removed sentence returns. Layers and captions shift forward with it. | |
| A: drag the end handle earlier past a tail CTA, drop | Outside layers are kept, not deleted | The CTA is flagged outside. The render skips it and the story still ends cleanly. | |
| A: press Undo trim, then inspect the receipt panel | Trim undo is a new version | Range, layer times and captions return to the pre-trim cut. The receipt says what moved, what went outside, and the caption counts. The new Edit id differs; the old artifact and review link still open. | |
| A: hand-edit a caption name over a retained sentence, then trim the start | Manual fixes survive | The hand-edited text is still there at the new time. It is not re-transcribed. | |
| A: Finish, then check the packet SRT and burned film | One caption lineage | Burned cues, SRT and packet cues have the same times and text as the Edit track. | |
| B: repeat the start trim, then open 4:5 | Multi-aspect rebind | The 4:5 Edit follows the same range with no stale badge on either aspect. | |
| B: Finish the 4:5 cut, then open the old 9:16 artifact | Old artifacts are immutable | The old artifact still plays its original cut. Only new renders carry the new Edit hash. | |
| Two tabs or Stories ± while an Edit is open: trim in one, save the other | 409 races and fail-closed Finish | The stale save is refused with a reload/Repair message. Finish refuses with “This story changed after its Edit was made. Open it in Edit and press Repair.” It never renders the plan without layers. | |
| Kill/deny the caption rebuild (or use a job with no writable data dir) and trim | Atomic failure | The trim fails with a plain message. Story range, Edit pointer, caption pointer and artifacts are unchanged. | |
