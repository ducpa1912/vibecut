# Wave 2 T2 — STT handoff

**Branch:** `rv/w2-t2-stt`
**Base:** `wave-2-base` (`eb13302`)
**HEAD:** branch tip after this handoff commit (reported in the wave reply)
**Tests:** 1004 baseline → **1033 passed** (`tests/test_stt.py` adds 29).

## What was built

1. **Transcription moved to `stt.py`.**
   - Apple SpeechAnalyzer, local Whisper, Groq and Deepgram now live in `stt.py`.
   - `pipeline.py` keeps compatibility names (`transcribe`, `transcribe_apple`,
     `_cloud_speech`, `read_transcript`, `attach_speech`, `whisper_models`,
     `WHISPER_MODELS`, `_apple_transcribe_helper`) so `app.py`, `audio.py`,
     `render.py` and the existing tests did not need changes.
   - `pipeline.analyze_source` calls `stt.transcribe_source`.
   - The old `pipeline._transcribe_workflow` remains as a deprecated shim for
     the pre-v2 route tests; production analysis never calls it.

2. **Apple helper emits real word ranges.**
   - `tools/transcribe_apple.swift` reads `result.text.runs`; each run's
     `.audioTimeRange` becomes a `words[]` row.
   - Requests `.transcriptionConfidence` as well.
   - Vocabulary is passed through `AnalysisContext.contextualStrings[.general]`
     (`--vocabulary '<json array>'`).
   - Verified with `swiftc -O -parse-as-library` (macOS 26.6 SDK).

3. **Whisper.**
   - `--word-timestamps True`.
   - `mlx-community/whisper-large-v3-turbo` is the default; the q4 turbo is the
     alternate. `whisper-small`/`medium` are normalised to turbo at runtime.
   - Existing compression/no-speech/logprob hallucination filters are kept.
   - Vocabulary is passed as `--initial-prompt`.

4. **Transcript v2** (`REVAMP_PLAN.md` §6.3), stored at
   `jobs/<id>/transcript/transcript_v2_<id>.json`:

   ```json
   {
     "schema": 2,
     "id": "tr_1761600000000_ab12cd34",
     "source_hash": "…",
     "engine": "apple",
     "model": "on-device-3b",
     "language": "en",
     "created": 1761600000.0,
     "hash": "sha256(canonical content)",
     "segments": [
       {"start": 0.0, "end": 2.4, "text": "Hello world.", "confidence": 0.91}
     ],
     "words": [
       {"w": "Hello", "start": 0.0, "end": 0.4, "confidence": 0.94, "segment": 0}
     ],
     "quality": {
       "coverage": 0.82,
       "mean_confidence": 0.91,
       "low_conf_words": 2,
       "drift_ms_p95": 18.0
     },
     "text": "Hello world."
   }
   ```

   - Canonical v2 files are write-once. A re-run gets a new `id`; identical
     content gets the same `hash`.
   - `transcript.json` is still written as a **legacy mirror** because the
     existing `/api/jobs/{id}/transcript` route only reads that name. The mirror
     is not the canonical record.
   - Captions record `transcript_id` on `CaptionTrack`.

5. **Chunking and resume (G3).**
   - 10 minute chunks, 5 s overlap (`stt.chunk_ranges`).
   - Words duplicated in the overlap are de-duplicated by text + start time.
   - Cache key = `sha256(audio_hash:engine:model:chunk_index)`, stored under
     `jobs/<id>/transcript/chunks/<key>.json`.
   - Every finished chunk is persisted before the next starts, so a crash
     resumes at the last finished chunk.

6. **Vocabulary.**
   - Global list: `settings.stt.vocabulary` / `settings.stt.names`.
   - Per-job list: `job.vocabulary` / `job.stt_vocabulary`.
   - Used as Apple contextual strings and Whisper `initial_prompt`, then a
     post-pass corrects case/fuzzy name matches with punctuation preserved
     (`vision.correct_ocr_text` + `difflib`).

7. **Captions from words.**
   - `captions.read_transcript_v2` loads the newest v2 file.
   - `read_transcript_segments` returns measured `words[]` when v2 exists.
   - `_word_cues` groups words into style-safe cues and keeps their measured
     start/end times; sentence boundaries still end a cue.
   - Legacy jobs without v2 keep the old interpolation path unchanged.

8. **Removed engines.**
   - OpenAI STT is gone from the engine set and `_cloud_speech` refuses it.
   - `auto` no longer picks a cloud provider. `auto`/`local` are local Whisper
     aliases; cloud providers only run when a route names them explicitly.
   - `openai_key()` remains because `audio.py` still imports it (T3/Claude Code
     owns the leftover cleanup).

## Known gaps / carry-over

1. **T3 / Claude Code engine-removal leftovers (unowned files):**
   - `workflow_config.STT_PROVIDERS` still lists `auto`, `openai`; its default
     STT workflow still names `mlx-community/whisper-small-mlx`.
   - `settings_store` defaults still say `provider: auto`,
     `model: mlx-community/whisper-small-mlx`.
   - `admin/catalog.py` still advertises `whisper-1` and small Whisper.
   - `app.py` settings validation still accepts `STT_PROVIDERS` from
     `workflow_config`, so an old `whisper-small` model is rejected when saving
     Setup until the T3 migration maps it to turbo. Runtime already normalises
     small/medium to turbo.
2. **Language “Auto”** does not yet run the §6.4 three-sample language ID pass.
   It falls back to the configured/settings language. Apple uses `en-US` when
   the language is unknown.
3. **`drift_ms_p95`** measures chunk-overlap disagreement, not error against
   hand-marked ground truth. The §6.5 corpus benchmark still needs a harness.
4. **Re-transcribe one story range** (§6.4 item 9) is not implemented; the
   track list did not include it.
5. **`transcript_id` propagation into artifacts/packet** is Wave 4 work. It is
   recorded on caption tracks now.
6. **Legacy shim:** `pipeline._transcribe_workflow(legacy=True)` retains the old
   route semantics for compatibility tests only. Its OpenAI branch cannot reach
   the network because `stt._cloud_speech` refuses `openai`.
7. **Explicit cloud failure** returns no transcript; it does not silently fall
   back to local Apple/Whisper. This is intentional (“cloud is explicit”), but
   the UI may want a retry-with-local action.
8. **Apple runtime smoke test** was not possible without the macOS 26 Speech
   asset installed; the helper compiles and its JSON contract is covered by
   fakes. No model pack or network is used by tests.
9. Caption cues are word-timed, but a single word group that spans more than
   `MAX_CUE` (4 s, e.g. very slow speech) still falls back to the existing
   even split inside `_fit_cue_text_and_timing`.
10. T2 has no Studio UI ownership; nothing under `static/studio/**` changed.
