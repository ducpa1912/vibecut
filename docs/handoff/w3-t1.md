## What was built

1. **Text layers from `overlays.py` validators.**
   - `overlays.edit_text_layer()`, `edit_text_layers()` and
     `plan_text_layers()` validate overlay inputs with the existing
     text/timing/anchor/box/z/style/opacity validators and return Edit
     `graphics` text entries.
   - Kind map: `hook`, `title`, `lower_third`, `cta` pass through; an overlay
     `caption` slot becomes an Edit `emphasis` word layer. `max_end` caps a
     layer at the story duration, same as `build_plan`.
   - Edit text layers keep output coordinates; the compiler adds the `rect`.

2. **`fx.py` — motion, graphic and beat-snap builders.**
   - Motion: `punch_in`, `snap_zoom`, `push`, `shake` (plus `motion(kind, …)`).
     Output is exactly what `edits.normalize_motion` accepts.
   - Graphics: `arrow`, `circle`, `underline`, `progress_bar`,
     `sticker`/`emoji` (plus `graphic(kind, …)`).
   - Builders drop the auto `mo01`/`fx01` id unless the caller supplies one,
     so several builders compose without id collisions; the Edit assigns
     list-index ids.
   - Bundled sticker set: 8 in-house RGBA PNGs (`star`, `heart`, `sparkle`,
     `fire`, `check`, `arrow_up`, `wow`, `speech`), 512×512, content-hashed.
     `asset {id, hash}` is filled from the file bytes.
   - Emoji map (11 glyphs) resolves to bundled stickers. No emoji font or
     platform glyph is used at render time.
   - Beat snap: `beat_times()` accepts `audio.beat_grid`’s
     `{"bpm", "beats"}` dict, plain seconds or `{t|time|start}` dicts;
     `beat_snap()` moves a time to the nearest beat inside ±120 ms;
     `snap_span()`, `snap_motion()` and `snap_graphics()` preserve duration
     and unrelated fields.

3. **`color.py` + eight `.cube` presets.**
   - `assets/luts/` holds `warm_film`, `cool_fade`, `vivid_pop`,
     `soft_matte`, `golden_hour`, `teal_orange`, `mono_contrast`,
     `clean_bright` as 17³ ffmpeg `lut3d` files.
   - Each file is generated deterministically from `edits.COLOR_PRESETS`
     (tone/colour only: exposure, contrast, saturation, temperature).
     Vignette, grain and sharpen stay as filters.
   - `color.preset_plan(name, use_lut=True)` zeroes the tonal sliders and adds
     `color.lut`, so the same look is not applied twice.
     `color.ensure_luts()` writes only missing/stale files;
     `color.lut_asset()` refuses a file that does not match its generator.

4. **`compose_render.py` changes for the new layers.**
   - Sticker layers resolve `asset_path` from the bundled set and verify the
     Edit’s content hash. A missing asset or hash mismatch skips the layer
     with `sticker_unavailable` / `sticker_hash_mismatch` warnings instead of
     burning the wrong art.
   - Raster descriptors include the asset only when present, so existing text
     and progress-bar hashes are byte-identical to Wave 2.
   - `compile_edit(..., beats=…)` snaps motion and graphic boundaries before
     compiling (the stored Edit and `edit.hash` never change). Compile output
     gains `beat_snap {enabled, beats, window}`.
   - Golden tests cover emphasis text, sticker, underline, raster hashes and a
     beat-snapped perspective filter string.

5. **Story render uses the current Edit (Wave 2 carry-over).**
   - `POST …/stories/{story_id}/render` and the story queue backend now
     resolve `story_edits["{set_id}:{story_id}:{aspect}"]`, load the immutable
     Edit, verify its clip snapshot hash against the current story, and pass
     it to `render.render_reel(edit=…)`.
   - No Edit, stale clips, unreadable sidecar or an aspect mismatch falls back
     to today’s plan path unchanged.
   - Edit captions are authoritative: an enabled track is loaded and burned;
     a disabled or deleted track burns none (no hidden legacy track).
   - The story render response adds `edit_id` / `edit_hash`. The render record
     stores both. No new routes.
   - `story_queue.py` needed no edit: `StoryRenderBackend.start()` already
     delegates to `_queue_story_render`, which now chooses the Edit. A unit
     test calls the backend directly.

6. **`artifacts.py` hash input only.**
   - `ArtifactSpec.edit_hash` is added to the spec payload only when non-empty,
     so legacy artifact ids and pinned links stay byte-identical.
   - Same Edit → same artifact id: verified live (repeat render returned the
     same artifact in 0.037 s).

## Known gaps

1. **No Studio ownership.** `static/studio/edit/layers/effects.js` (W3 T4)
   still shows placeholders; this track supplies the backend builders and the
   compile/render support only.
2. **Beat snap is not auto-applied by `render_reel`.** `fx` and
   `compose_render.compile_edit(beats=…)` are ready, but `render.py` (not
   owned by this track) does not pass a beat grid, and W3 T3 owns the music
   grid. Story renders today use the Edit’s stored times unchanged.
3. **Animation is still progress-bar only.** Arrow draw-on, underline draw-on
   and sticker pop need per-frame drawing in `render.py`, which is outside this
   track. Arrow, circle, underline and sticker render as static PNGs today.
4. **Emoji coverage is the fixed 8-sticker set** (11 glyph aliases). Arbitrary
   emoji are refused on purpose; adding one means adding a PNG and an alias.
5. **LUT paths are absolute** (as stored by the Edit). Moving the install
   leaves a stale path; the content hash check fails loudly. A later packet /
   asset-normalisation pass (W4) can make them install-relative.
6. **Real-footage frame SSIM is 0.965–0.987**, under the 0.98 synthetic gate on
   B’s dense garden footage. The endpoint is JPEG q=2 and the final has one
   more H.264 generation; the layer graph matches. A lossless frame path or a
   PNG response is a Wave 5 preview/perf item (`render.py` owner).
7. **Flow 1 is not in this track.** A’s large baked-in title remains in frame
   (T2 owns Clean); the hook text intentionally sits over it in this slice.
8. **Captions-enabled Edit was unit-tested, not live-run.** Both live Edits had
   `captions.enabled=false`; the disabled path avoided hiding the source’s
   burned subtitles for the Flow 2 check.
9. **Edit re-render clears the legacy `renders/reel_<target>.mp4`.** Artifact
   media is copied per artifact id, so old artifacts are safe, but the bare
   job render file always shows the newest Edit.
10. **`artifacts.py` covers only `edit.hash`.** `transcript_id` and audio/music
    hashes remain W4 T1.
11. **Live corpus was 2 fixtures only.** Each produced 2 stories at their
    length; no 4:5 live render was run (4:5 Edit selection is unit-tested).
12. **Story queue needed no code.** The backend is the same
    `_queue_story_render`; the queue test exercises `StoryRenderBackend`
    directly, and the live renders used the same handler.
