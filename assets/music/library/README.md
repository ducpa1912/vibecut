# My own music

In the Voice Room lane the library is `data/music`, not this folder. Drop your own tracks there and pick them in **Music → My own track** in the
render panel. The track selector lists every audio file in this folder.

Supported: `.mp3`, `.wav`, `.m4a`, `.aac`, `.flac`, `.ogg`, `.opus`.

Mood tags also read from file names, so `sunset-warm-piano.mp3` can be chosen
automatically when the selector stays on **Auto mood**.
