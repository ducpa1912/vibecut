# CC0 music folder

Drop royalty-free tracks here. VibeCut picks one by mood when the render uses
**Music → CC0 library** and the track selector stays on **Auto mood**.

The mood comes from the file name. Include words like:

`calm`, `ambient`, `soft`, `warm`, `upbeat`, `energetic`, `groove`, `cinematic`,
`dramatic`, `piano`, `guitar`, `synth`, `lofi`, `nature`, `tense`.

Example: `morning-garden-calm-piano.mp3` matches calm/warm moods.

Good CC0 / royalty-free sources:

- Pixabay Music — https://pixabay.com/music/ (check each track page)
- Mixkit — https://mixkit.co/free-stock-music/
- Free Music Archive CC0 — https://freemusicarchive.org/
- YouTube Audio Library — https://studio.youtube.com/ (license per track)
- Uppbeat free tier — https://uppbeat.io/ (credit required on some tracks)

Keep a note of each track's license next to the file if you share the reel.
