7. Finish M1; what Clerk, R2 and Postgres actually are

User
update the doc like above so they have the git repo and everything they need. then finish m1, what is clerk, which r2, it suppose to have postgres, where is it now?
Clerk Hosted identity/OAuth. Issues the session JWT; the API verifies JWKS. Not a database and stores no video.
Postgres Metadata: users, library, beats, detections, jobs, usage. Not provisioned. Only PGlite tests. Hyperdrive is a pooler, not a database.

Queues duckclean-jobs and duckclean-jobs-dlq; not created.

12. Clerk is not Next-only

User
note vite clerk only next, vue and some other

Vite is the bundler, not a framework. Clerk’s React SDK works in a Vite SPA; Next.js is not required. Clerk also ships SDKs for React Router, Astro, TanStack React Start, Vue, Nuxt, Expo, Electron, Android and iOS.

The repo later moved from the deprecated @clerk/clerk-react to @clerk/react 6.18.6. The current React package uses Show when="signed-in" / "signed-out" instead of SignedIn/SignedOut. Commit 62d528c documented the framework note; the package migration landed later at 699b41d.

14. Merge fixes

User
fix everything so it can merge and then create a hand-over prompt so freebuff understand the project better
  • Retry: createOrRetryJob resets a failed/cancelled job; new run only after job succeeds.
  • Scope: API filters beats; worker reads selected; unread beats stay pending; no false empty.
  • Engine truth: RapidOCR only; PaddleOCR rejected.
  • Beat reset: every detection run clears old has_target/status/detection_run_id.
  • Coverage: effective fps scales only on real truncation; duplicate-frame inheritance does not lower it.
  • Masks: union of all observed glyph quads per member; mask kind preserved (glyph/region).
  • Poster: HEAD-verified like the proxy.
  • Worker errors: DetectError → non-retryable payload_invalid 422.
  • Tiling: 3×3 grid allowed; MAX_TILES=9.
  • Grouping: text lines close in one visual area become one group with separate members.
  • Setup: make setup and CI install worker[dev,ocr].
  • Dev DB: migrations run directly, no nested transaction around BEGIN/COMMIT.
  • Frontend: @fontsource moved to web; Clerk React 6; audit clean.
  • Detection UI: panel with run state, frames, coverage, OCR/logo availability, warnings, groups.

Tests: 68 API, 40 worker. Typecheck, lint, mypy, ruff, build, Prettier and npm audit --omit=dev all pass. Commit 7639128; Clerk/audit follow-up 699b41d.
